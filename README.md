# show-me-the-money

Assorted scripts that solved problems at some point. Your mileage may vary.

## Scripts

- `bulk-change-commit-email.sh` - Bulk update git commit emails
- `Run-Ngen.ps1` - Run .NET Native Image Generator
- `Start-Numlock.ps1` - Enable NumLock
- `Stop-Numlock.ps1` - Disable NumLock

The NumLock scripts exist because sometimes you just need NumLock to behave.
